页面交互与接口对应 · 设计草案

会话与 Issue 分开；一个会话可关联多条独立 Issue。Issue 页面可进入已关联、可读且就绪的主房间与 Leader 房间；Leader 房间只读。每条 Issue 独立计划、验收和主 ChangeSet。

这是可丢弃的内存原型，刷新重置，不连接真实模型、仓库或接口。Issue 栏创建默认新建会话。提交前取消或表单校验失败不创建记录；本地模拟没有网络请求，不能说明请求发出后取消会回滚。首次消息后的准备是页面演示，新对象下的实际启动触发仍待细化。建立 Issue 的表单、消息来源及返回提示不冻结内容快照、消息目标路由或房间共享拓扑。导航来源不是执行授权。

窗口外分别模拟房间就绪、消息投递、核查、Manager 回复及指定 Issue 的计划／Leader 房间就绪。创建 Issue 本身不代表派工。消息归属、权限、幂等、恢复和 SSE 尚未运行验收。
