  1. 首次发送：POST /api/projects/{projectId}/draft-issues。仅登记 Draft Issue 与首条消息；返回草稿身份及主房间准备状态。没有正式 Issue、主 ChangeSet 或执行任务。
  2. 草稿讨论：读取主房间快照；POST /api/draft-issues/{draftId}/messages 追加消息。收到消息、Manager 处理、用户明确创建分别记录。
  3. 明确创建：POST /api/draft-issues/{draftId}/formalizations。核验用户意图、权限、草稿修订及幂等键；正式 Issue、主 ChangeSet 和后续待办同事务保存。成功后继续原来的对话入口。
  4. 仓库房间：Manager 建立并关联房间后，由 SSE /api/conversations/{conversationId}/events 通知；REST 补查当前快照。仅 Ready 且有读取权限的房间可进入，当前人类仍通过 Manager 沟通。
