## 三项页面候选

1. 原密钥默认保留，明确点“替换 API Key”才进入填写；确认后先加入配置草稿，与供应商连接／模型一起保存。原型输入框只读，仅“填入演示占位”，不收真实密钥。代价是替换多一次加入草稿动作，避免误改当前配置。
2. 保存前显示供应商、Base URL、保留或替换密钥、模型数量的摘要。密钥正文从不出现在摘要／回执；新完整快照不自动切换项目或在途Issue，也不自动测试。代价是多一次保存确认。
3. 保存结果未知时保留原操作，可查询、稍后核查，或明确“终结原保存”。确认说明已保存会返回原结果，未保存会阻止本次请求以后保存，不撤销已保存配置。只有取得确定拒绝或“原操作已终结，未保存”回执才直接回草稿，重新填写必要Key后以新操作保存；关闭结果也未知时继续核原操作。代价是增加一次显式终结和确认过程，终态取得前相关草稿暂不能发起另一保存。

## API责任与未定字段

沿既有保存完整快照、只写密钥、固定项目版本、不自动测试／应用、未知保留原操作的目标。候选机器协议现由[模型浏览器稿§3.1](model-settings-browser-api-draft.md#31-r01终结原保存解除未提交操作的未知状态)及[后端模型稿§3.4](backend-model-operations-draft.md#34-r01无原输入的原子终结)维护；本页面不复制另一套Schema，也不把候选标为采用。

| 页面动作 | 后续API必须补齐的责任 |
| --- | --- |
| 读取已保存配置 | 当前owner资格、可披露配置快照及密钥存在／可用观察；不返回原始Key，存在不等于模型远端接受。 |
| 保留／替换并保存 | 明确密钥意图；完整连接／模型快照与密钥版本的原子保存、并发比较、合法输入、当前权限、原操作身份。默认保留不能误当置空或新建密钥。 |
| 保存结果未知 | 有权查询原操作，或明确关闭同一个saveId；未找到不能自行判失败或换键重发。不在恢复索引、日志、URL或事件中保存密钥。原输入丢失不妨碍查询／关闭。 |
| 终结原保存 | 与原保存竞争同一actor／saveId唯一槽位；已提交返回原结果，空槽位原子记录closed_without_save并拒绝迟到保存；不得以关闭弹窗或等待时间替代。 |
| 成功回执与回读 | 回执只说明本次结果，当前配置可已变化；回读当前快照与项目引用分开。新快照测试不继承旧观察，项目仍原固定版本。 |
| 明确未保存 | 持久rejected或closed_without_save回执才支持直接回草稿；重新输入必要Key并明确新操作。网络失败、无权404、查询无记录404与清理410都不等于未保存。 |

现行[首批浏览器契约](first-batch-browser-api-contract.md)不定义供应商Key保存，也不能拿项目configuration PATCH代替。模型[专用应用](model-project-apply-design.md)和逐模型测试保持独立待补，不擅自采用认证草案C的秘密存储／导入方案。

## 终结与恢复的页面分支

保存发出后仍立即清Key内存，浏览器只保留非秘密草稿、原saveId和恢复入口，不重新索要Key重放原请求。终结不带Key或原配置输入，不在当前供应商之外推断目标；服务器按真实actor核验同槽位。

| 实际响应 | 页面表达与动作 |
| --- | --- |
| 原保存committed | 展示原保存结果，再读取当前配置；不称“取消成功”，不回滚、不自动再保存。 |
| rejected或closed_without_save | 明确这次不会保存；允许回到非秘密草稿，由用户重新输入必要Key、核对当前供应商修订并确认新的saveId。 |
| close响应丢失、503或查询MODEL_SAVE_NOT_FOUND | 保留“仍待确认”；查询原saveId或重试同一close，不允许换键保存。 |
| 401 | 清主体敏感状态，同一主体恢复后回原操作；切换账号不能终结或读取原主体操作。 |
| 无动作资格403、结果不可披露404或资格未知503 | 按真实权限状态解释，隐藏无权内容；不能显示未保存或用另一主体继续。 |
| 原记录已清理410 | 显示记录已清理、原键不可复用；另读有权当前配置，由用户重新做业务选择，不自动重建原供应商或声称其从未保存。 |

两标签同时显示未知时，共享非秘密原操作定位即可。确定结果可使另一标签回读；未收到同步通知不能自动新建保存。服务器同槽位互斥负责拒绝迟到原请求，浏览器请求代次防旧查询覆盖新结果，不以标签锁作为幂等保证。

## 原型与剩余范围

当前内存保存只有占位布尔值与预置配置；保存阶段、结果未知、查询仍未知、明确成功／明确未保存均为可切换样例。新片段覆盖串联入口的密钥按钮和供应商保存／查询，原稿历史快速成功行为仍在原HTML内保存，不作真实恢复依据。

仅同一页面实例保留草稿和原操作。没有真实API、密钥、加密、数据库、费用或模型调用；DOM状态不是安全清理验收。R01已补候选协议和上述页面分支，不能据文档或模拟结果宣称跨刷新／多标签、权限、事务互斥、秘密清理或真实恢复已经验证。历史密钥、出站和其他整体设计按六项待审包继续审阅。当前三项UI及本次终结增量待用户采用，F05不标整行完成。
