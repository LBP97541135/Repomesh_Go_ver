① 账号与身份

谁在这个平台上：组织、人、Agent、集成凭据
organizations
组织：最高层租户单位（多租户隔离单位，一人只属一个组织），所有数据都挂在组织下
由哪些表来： organizations（原样保留）
字段类型标记说明
idUUIDPK主键
name字符串必填组织名
created_at时间必填创建时间
users
人：账号与登录态，一人只属一个组织（多租户：数据按组织隔离）。审批、逐级审核、驳回都是"人"这个动作主体
由哪些表来： local_human_accounts local_human_sessions
字段类型标记说明
idUUIDPK主键
organization_idUUID必填索引所属组织（一人一组织）
username字符串必填唯一登录名
display_name字符串必填显示名
password_hash字符串必填密码哈希（盐含在哈希内）
org_role字符串必填组织内角色（组织管理员/普通成员）
active布尔必填是否启用
session_token_hash字符串可空当前会话令牌哈希（会话表 1:1 并入）
session_expires_at时间可空令牌过期时间

agents
Agent 名册：Leader（总）、Manager（仓库）、Worker、数据库测试团队每个可干活的身份
由哪些表来： agent_principals（改造保留）
字段类型标记说明
idUUIDPK主键
organization_idUUID必填所属组织
role字符串必填索引角色（leader=总/manager=仓库/worker/db-test-team）
