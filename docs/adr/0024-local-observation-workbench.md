# ADR 0024：观测与评测平台全本地运行

日期：2026-09-19。状态：accepted（部署方向）；实现与验收见当前交接。

## 决定与替代范围

用户明确要求全本地方案。AgentLoop 官方 Launcher 是云端实验的本地发起端，不能满足此要求。默认入口改为 RepoMesh 本地观测工作台，复用独立 `repomesh-observe` 工具及其不可变证据档案，不要求 AgentSpace、AccessKey、云端 Dataset 或 Evaluator。

本决定替代观测 Spec 和首轮开发计划中“由 AgentLoop 承担默认查询、数据集及评估展示”的部署选择；来源身份、不可变证据、缺失保持 unknown、独立验收与 Agent 能力分开等规则继续有效。AgentLoop 导出适配保留为可选能力，不在全本地启动流程中调用。

## 实现范围

- `repomesh-observe serve` 托管本地页面、档案查询、数据集下载、固定折扣用例执行和 OTLP HTTP 接收。页面资源打包在二进制内，无外部 CDN。
- 业务事实、检查结果、HTTP 证据及 OTLP Span 保存在本机私有目录。页面支持查询、详情、关联与结果比较；相同身份的冲突或损坏记录明确报错，不显示为成功。
- 只监听回环地址；页面不能指定任意命令、任意文件或远端执行目标。已有显式 CLI manifest 接口保持原范围。
- 运行固定用例仅启动本机临时 HTTP 服务，不调用云模型。用户随后明确允许 DeepSeek API：可选模型评审按单条 Trial 显式发起，凭据只放本机私有配置，评审输入、输出及用量在本机归档，与业务验收分开。此处“全本地”保证观测及确定性验收闭环；DSH 和模型推理的接入仍按真实配置与独立验收，不伪造已接入状态。
- 这是独立管理工具，不增加产品业务进程权限，不改现有业务库迁移与共享实例，不另建产品调度器。

## 验收

本地页面可读持久证据并执行真实固定用例；pass／fail／unknown 可追溯至检查与 HTTP 响应；OTLP 经落盘后重启可查询、重复上报幂等、冲突拒绝；越界文件、跨站写入和非回环绑定被拒绝。浏览器运行时所有请求只访问本机。启动、停止和重启操作核对进程身份。
