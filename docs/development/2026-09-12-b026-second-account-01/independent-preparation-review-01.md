# 第二账号验收准备独立复核 01

## 范围

复核者只读检查本目录的 README、PLAN、验收记录，以及 HANDOFF 和 IMPLEMENTATION-PLAN 的入口链接。没有执行 GitHub 配置、账号操作、RepoMesh 登录、数据库写入或文件编辑。

## 首轮发现与处理

- P1：原计划只使用一个 A、B 共同可见的私仓，无法证明账号 A 的结果没有泄露仅账号 B 可见的仓库。计划已增加 B 持有、A 不可见且独立 selected-repositories 安装的专用私仓，以稳定 ID 完成可区分检查。
- P1：失败路径原先没有明确强制恢复临时公开的 App。计划已把恢复设为成功、失败或中途阻塞后的必做收尾，并要求移除 B 的临时 App 安装、恢复 App private、保持 B 对 A 私仓权限已移除。
- P2：原计划要求等待超过 60 秒，但实际记录字段不够明确。计划已要求保存 allowed 观察、移除完成和重查三个时间，以及重查相对 allowed 观察的实际秒差。

## 终轮结论

终轮复核没有开放 P0/P1/P2：

- B-only 样本与 A-owned 撤权样本用途分离，能够分别验证跨账号不披露与用户读权撤回；
- refresh-02 epoch 5 的门槛保持，确认刷新和 LIVE-10 完成前不会开始第二账号外部变更；
- 任一验收失败后仍必须恢复 App 可见性、安装和协作者状态；
- 文档只记录 `PREPARED_NOT_RUN`／`NOT_RUN`，没有把账号创建、配置准备或复核冒充真实通过；
- 本地链接有效，没有写入秘密或私仓名称。

本复核只证明计划可执行和证据边界完整，不证明 LIVE-05、LIVE-08、B02.6 或 B02 已通过。
