# 验收会话维持

Windows Node PID 51412 已启动独立会话维持脚本，文件见 `session-keepalive-01.mjs`。脚本只针对现有 RepoMesh 主 target，且每次请求前检查页面仍在固定 origin。立即执行一次正常 GET /api/session，随后每 10 分钟执行一次，截止于当前会话原有的绝对期限 2026-09-13T03:48:40Z。

脚本不会登录、重连、读取 Cookie 值或修改数据库期限。会话 401、账号 ID 变化或浏览器连接丢失时停止；主标签暂时位于 GitHub 时跳过该次请求。网络失败记录固定错误码并在下一间隔再试。证据输出为 `/tmp/repomesh-b02-live/session-keepalive-01.jsonl`，仅保存时间、HTTP 状态、本地账号 ID 及连接观察状态，不保存 csrfToken。

此进程只维持正常浏览器活跃度，不执行 GitHub 令牌刷新，不替代自然刷新前后的只读数据库快照。最终刷新基线仍待权限恢复、第二账号与失权样本完成后封存。若后续重连改变会话绝对期限，重新核对并另建运行记录，不能把旧脚本的期限当成新会话期限。
