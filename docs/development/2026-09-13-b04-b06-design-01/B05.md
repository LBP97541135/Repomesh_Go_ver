## 调用者与责任

用户先为已保存的单模型建立预览，明确可能收费，再登记一次测试。Web 只登记，coordinator 的 TestRunner 负责一次发送和原操作观察。SendPermit 必须来自本进程一次确认提交的事务，无法从数据库恢复成再次发送许可。证据不足时费用为未知，GET 不发送请求。

用户应用模型时预览候选与项目旧固定配置，ApplicationService 持一个事务，projects.ReplaceModel 完整保留 execution。无实际变化仍写稳定回执并消费预览，不制造修订。C05 随项目 GET 返回固定参数，C06 给可读原模型的历史定位；受限原模型不阻止配置修复。

[b05.go.txt](b05.go.txt) 和 [frontend.ts.txt](frontend.ts.txt) 提供类型及声明。modelbudget 是两个真实消费者共用的有限 request 记账模块，只承担窗口、预留和保守消费；无金额结算、调度或网络。models/最终用例依赖它，它依赖 projects 中的政策值类型；projects 通过组装注入窗口初始化和同事务只读额度观察函数，不反向导入 modelbudget。函数只接 caller tx，不自行提交或外发。

| 入口 | 输入／输出及失败责任 |
| --- | --- |
| TestService.Preview / Submit / Get | 固定目标、预览、testId及收费确认；错误不自动重发，202只是持久登记 |
| TestRunner.authorizeOneSend / sendOnce | 锁后再核权限/秘密/政策；事务内消费1次，提交未知不发送，进程重启只核查 |
| recordObservation / reconcile | 只采纳同 test/externalOperation 的白名单事实，迟到者无权覆写正式状态或新操作 |
| ApplicationService.Preview / Apply / Get | 原项目、configuration、execution与候选CAS；重放优先于期限；冲突整笔不改配置 |
| projects.ReplaceModel | caller持项目及目录锁；原 execution 全量复制，比较后no-op或新修订 |
| modelbudget.Store | 同 tx 接受/消费/释放；只有可证明未发送才能释放，UTC换日不清未核责任 |
| models.UnknownMaintenance与coordinator本地CLI | 从实际DB session_user、部署身份和专用role取得不透明principal并每tx重核；只读inspect及带原closeKey的unknown close校验两类带外材料和不可变绑定 |

前端在实施时扩展现有`web/src/modelRecovery.ts`，只共享locator、浏览器存储和读取代次。`provider_save`、`model_test`、`model_apply`和`issue_create`保留各自parser、reducer和重试规则。`web/src/projectRecovery.ts`继续独占B03的project_create/project_update，不迁入模型恢复模块。

旧调用者必须同批迁移后再删除`SaveLocator`。`ModelSavePage.tsx`改用`ProviderSaveLocator`和保存专用状态；`ModelSettingsPage.tsx`保留B04存储键与Key清理时点；`session.ts`改调`clearRecoveryPayloads`并继续单独调用B03的`clearAllOperationInputs`；`model.test.mjs`保留B04断言并覆盖新增locator和独立reducer。该结论是声明级迁移要求，当前未修改产品前端。
