## 执行流程

1. Read the Principles section of the poteto-mode skill。
2. Phase A: Frame。核对批次边界、现行依据与附件格式。
3. Phase B: Design the workflow。按 B00-B03、B04-B06、B07-B08、B09-B11 分配独立草稿输出，确定 Markdown 为单一内容源。
4. Phase C: Run the loop。逐组编写并核对，再整合生成 HTML。
5. Phase D: Keep the audit trail。记录影响结构和采用边界的决定。
6. Phase E: Verify and hand back。独立复核语义，检查生成、链接和实际页面。
