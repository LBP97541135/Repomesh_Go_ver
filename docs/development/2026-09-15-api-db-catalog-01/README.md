## 关键设计收口

- B08 复用前序 API 与表，验收证据留在批次文档中。
- B07 只持有 Issue 房间关联与最新观察；SSE 的 changed 由事件读取时计算。普通 Conversation 的运行会话不依赖 Issue 房间存在。
- B10 建立轮次、每仓不可变计划修订、每轮每仓当前指针和仓库事项的物理提案；B11 复用。计划写入先有轮次和修订，再登记指针，没有互相必填的插入环。
- RepositoryIssue 沿用已采用业务身份，首次真实委派登记，跨任务和轮次复用；选仓、计划和房间读取不补造事项。
- 执行关联以同 Issue、同仓库复合外键闭合。可空房间不能绕过项目归属。替补许可有证据 CHECK、不可回退的执行状态和持有任务行锁的历史核查。
- 结果采纳只保存最终裁决；needs_recheck 保留核查责任，不占用不可变最终结果的唯一位置。

这些取舍减少重复状态，并把业务身份、事务约束和生命周期写成可实施的设计。具体采用与实现仍按所属专题推进。
